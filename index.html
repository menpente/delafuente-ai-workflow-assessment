03 — Evidence, not magic

AI can create value. It can also destroy it.

Gains depend on the task, the worker, the implementation and the quality of the human–AI workflow. That's why every assumption here is editable instead of one universal "AI uplift".

+14%

Average productivity gain across 5,179 customer-support agents using a generative-AI assistant.

>25%

Faster completion for 758 BCG consultants on tasks inside the model's capability frontier.

−23%

Performance on a task outside that frontier, same study. "Use AI everywhere" is not a strategy.

The point is not to automate the maximum amount of work. It is to find the workflow where AI improves speed, quality or capacity — without weakening judgment, control, privacy or reliability.

04 — How the estimate works

Transparent assumptions. No "AI saves 40%" hand-waving.

An LLM is not a synonym for automation. If a process is deterministic, use deterministic technology: n8n or code for orchestration, ordinary APIs and rules for predictable steps, and an LLM only where semantic interpretation is needed.

Subtract the real cost

Implementation and recurring software costs give year-one net value and payback.

Formula
released hours = people × hours/week × 52 × AI-suitable share × time reduction × adoption
gross value = released hours × loaded hourly cost
net value = gross value − implementation − annual software
ROI = net value ÷ year-one investment
A scenario model, not a financial forecast.
